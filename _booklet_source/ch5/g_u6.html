حلول الوحدة 6

حلول الاختبار التجريبي 1شيّك

1.1 False↩ الورقة
Let \(n = 4\). Then \(n^2 + n + 1 = 16 + 4 + 1 = 21 = 3 \cdot 7\), which is not a prime number. Thus, \(n = 4\) is a counterexample.أول ثلاث قيم تعطي 3 و7 و13، وكلها أولية. الفخ: لازم توصل لـ \(n = 4\).
1.2 True↩ الورقة
Assume, to the contrary, that there is a largest negative real number, say \(r\). Since \(r \lt r/2 \lt 0\), it follows that \(r/2\) is a negative real number that is larger than \(r\). This is a contradiction.توأم «ما فيه أصغر عدد موجب»: «أصغر» صارت «أكبر»، و«موجب» صارت «سالب».
1.3 True↩ الورقة
Assume, to the contrary, that \(\sqrt{5}\) is rational. Then \(\sqrt{5} = a/b\), where \(a, b \in \mathbb{Z}\), \(b \ne 0\) and \(a/b\) has been reduced to lowest terms. Then \(a^2 = 5b^2\). Thus \(5 \mid a^2\), and so \(5 \mid a\). So \(a = 5c\) for some \(c \in \mathbb{Z}\), and \(25c^2 = 5b^2\), that is, \(b^2 = 5c^2\). Thus \(5 \mid b^2\), and so \(5 \mid b\). Since \(5 \mid a\) and \(5 \mid b\), this is a contradiction since \(a/b\) has been reduced to lowest terms.قالب \(\sqrt{2}\) نفسه، و«زوجي» صارت «يقبل القسمة على 5».
2 (1)مباشر↩ الورقة
Assume that \(n\) is even. Then \(n = 2k\) for some integer \(k\). So \(7n + 3 = 14k + 3 = 2(7k + 1) + 1\). Since \(7k + 1\) is an integer, \(7n + 3\) is odd.
2 (2)عكس النقيض
Assume that \(7n + 3\) is even. Then \(7n + 3 = 2k\) for some integer \(k\). So \(n = (7n + 3) - 6n - 3 = 2k - 6n - 3 = 2(k - 3n - 2) + 1\). Since \(k - 3n - 2\) is an integer, \(n\) is odd.
2 (3)تناقض
Assume, to the contrary, that there exists an even integer \(n\) such that \(7n + 3\) is even. Then \(n = 2x\) and \(7n + 3 = 2y\) for some integers \(x\) and \(y\). Hence \(14x + 3 = 2y\), and so \(3 = 2y - 14x = 2(y - 7x)\). Since \(y - 7x\) is an integer, 3 is even, which is a contradiction.

حلول الوحدة 6

حلول الاختبار التجريبي 2شيّك

1.1 False↩ الورقة
Let \(n = 3\). Then \(n^2 + 2 = 11\) and \(3 \nmid 11\). Thus, \(n = 3\) is a counterexample.
1.2 True↩ الورقة
Assume, to the contrary, that there is a smallest positive rational number, say \(r\). Then \(r = a/b\) for some integers \(a\) and \(b\) with \(b \ne 0\), and so \(r/2 = a/(2b)\) is a positive rational number. Since \(0 \lt r/2 \lt r\), this is a contradiction.
1.3 True↩ الورقة
Assume, to the contrary, that \(\sqrt[3]{2}\) is rational. Then \(\sqrt[3]{2} = a/b\), where \(a, b \in \mathbb{Z}\), \(b \ne 0\) and \(a/b\) has been reduced to lowest terms. Then \(a^3 = 2b^3\), so \(a^3\) is even, and so \(a\) is even. So \(a = 2c\) for some \(c \in \mathbb{Z}\), and \(8c^3 = 2b^3\), that is, \(b^3 = 4c^3 = 2(2c^3)\). Thus \(b^3\) is even, and so \(b\) is even. Since \(a\) and \(b\) are even, this is a contradiction since \(a/b\) has been reduced to lowest terms.
1.4 True↩ الورقة
Let \(f(x) = x^3 + x - 1\). Since \(f\) is a polynomial function, it is continuous on \([0, 1]\). Now \(f(0) = -1\) and \(f(1) = 1\). Since 0 is between \(f(0)\) and \(f(1)\), it follows by the Intermediate Value Theorem of Calculus that there is a number \(c\) between 0 and 1 such that \(f(c) = 0\). Hence \(c\) is a solution.
2 (1)مباشر↩ الورقة
Assume that \(n\) is odd. Then \(n = 2k + 1\) for some integer \(k\). So \(5n - 3 = 10k + 2 = 2(5k + 1)\). Since \(5k + 1\) is an integer, \(5n - 3\) is even.
2 (2)عكس النقيض
Assume that \(5n - 3\) is odd. Then \(5n - 3 = 2k + 1\) for some integer \(k\). So \(n = (5n - 3) - 4n + 3 = 2k - 4n + 4 = 2(k - 2n + 2)\). Since \(k - 2n + 2\) is an integer, \(n\) is even.
2 (3)تناقض
Assume, to the contrary, that there exists an odd integer \(n\) such that \(5n - 3\) is odd. Then \(n = 2x + 1\) and \(5n - 3 = 2y + 1\) for some integers \(x\) and \(y\). Hence \(10x + 2 = 2y + 1\), and so \(1 = 2y - 10x = 2(y - 5x)\). Since \(y - 5x\) is an integer, 1 is even, which is a contradiction.

البطاقات الخمس

  1. مثال مضاد: جرّب ← احسب ← احكم.
  2. تناقض: نعكس ← نمشي ← تناقض.
  3. ثلاث طرق: الفرق في أول سطر (تحت).
  4. وجود: اختر ← تحقق ← اختم.
  5. نفي وجود: اقلب ← خذ أي x ← اثبت.

خريطة القرار

  • Disprove + For every ← 1
  • Prove + There is no / irrational ← 2
  • Prove … by (a), (b), (c) ← 3
  • Prove + There exists ← 4
  • Disprove + There exists ← 5
  • Prove or disprove: جرّب 4 قيم أول.
