نفس صيغة ميد 1447. شغّل مؤقت 30 دقيقة، وحل على ورقة أو صفحات فاضية. لا تفتح الحلول قبل ما يخلص الوقت.
Q: Prove or disprove the following:15 marks
1. For every positive integer \(n\), \(2^n + 1\) is a prime number. (2 marks)
2. There is no smallest positive rational number. (3 marks)
3. The real number \(\sqrt{5}\) is irrational. (3 marks)
4. There exists an integer \(n\) such that \(n^2 + n + 1\) is even. (3 marks)
5. The equation \(x^3 + x - 1 = 0\) has a unique real number solution between \(x = 0\) and \(x = 1\). (4 marks)

بعد ما تخلص

  • كل فقرة بدأت بسطر الحكم: True أو False.
  • في False كتبت القيمة والحساب، أو برهان لكل n (لو الجملة «يوجد»).
  • في التناقض بدأت بـ Assume, to the contrary.
  • في «حل وحيد» كتبت الوجود والوحدانية.
حلول الوحدة 6

حلول الاختبار القصيرشيّك

1. False
Let \(n = 3\). Then \(2^3 + 1 = 9 = 3 \cdot 3\), which is not a prime. Thus, \(n = 3\) is a counterexample.\(n = 1\) و \(n = 2\) يعطون 3 و5 (أوليين). أول قيمة تفشل \(n = 3\).
2. True
Assume, to the contrary, that there is a smallest positive rational number, say \(r\). Then \(r = a/b\) for some integers \(a\) and \(b\) with \(b \ne 0\), and so \(r/2 = a/(2b)\) is a positive rational number. Since \(0 \lt r/2 \lt r\), this is a contradiction.نفس سؤال ميد 1447، ومعه سطر «ليش r/2 نسبي».
3. True
Assume, to the contrary, that \(\sqrt{5}\) is rational. Then \(\sqrt{5} = a/b\), where \(a, b \in \mathbb{Z}\), \(b \ne 0\) and \(a/b\) has been reduced to lowest terms. Then \(a^2 = 5b^2\). Thus \(5 \mid a^2\), and since 5 is a prime, \(5 \mid a\). So \(a = 5c\) for some \(c \in \mathbb{Z}\), and \(25c^2 = 5b^2\), that is, \(b^2 = 5c^2\). Thus \(5 \mid b^2\), and so \(5 \mid b\). Since \(5 \mid a\) and \(5 \mid b\), this is a contradiction since \(a/b\) has been reduced to lowest terms.قالب \(\sqrt{2}\) نفسه، و«زوجي» صارت «يقبل القسمة على 5».
4. False
We show that if \(n \in \mathbb{Z}\), then \(n^2 + n + 1\) is odd. Case 1. \(n = 2k\) for some \(k \in \mathbb{Z}\). Then \(n^2 + n + 1 = 4k^2 + 2k + 1 = 2(2k^2 + k) + 1\), which is odd. Case 2. \(n = 2k + 1\) for some \(k \in \mathbb{Z}\). Then \(n^2 + n + 1 = 4k^2 + 6k + 3 = 2(2k^2 + 3k + 1) + 1\), which is odd. Hence there is no integer \(n\) such that \(n^2 + n + 1\) is even.نفي وجود بالحالات، مثل مثال 15.
5. True
Let \(f(x) = x^3 + x - 1\). Since \(f\) is a polynomial, it is continuous on \([0, 1]\). Since \(f(0) = -1\) and \(f(1) = 1\), it follows by the Intermediate Value Theorem of Calculus that there is \(c \in (0, 1)\) with \(f(c) = 0\). For uniqueness, assume, to the contrary, that there are two solutions \(a\) and \(b\) with \(0 \lt a \lt b \lt 1\). Then \(a^3 \lt b^3\) and \(a \lt b\), so \(0 = a^3 + a - 1 \lt b^3 + b - 1 = 0\), which is a contradiction.الوجود بالقيمة الوسطى، والوحدانية بالتناقض، مثل مثالي 11 و12.

البطاقات الخمس

  1. مثال مضاد: جرّب ← احسب ← احكم.
  2. تناقض: نعكس ← نمشي ← تناقض.
  3. ثلاث طرق: مباشر: افترض P ووصّل لـ Q. عكس النقيض: افترض عكس Q ووصّل لعكس P. تناقض: افترض P وعكس Q ووصّل لمستحيل.
  4. وجود: اختر ← تحقق ← اختم.
  5. نفي وجود: اقلب ← خذ أي x ← اثبت.

خريطة القرار

  • Disprove + For every ← 1
  • Prove + There is no / irrational ← 2
  • Prove … by (a), (b), (c) ← 3
  • Prove + There exists ← 4
  • Disprove + There exists ← 5
  • Prove or disprove: جرّب ثلاث قيم أول.

الفخاخ

  • أول قيمة ممكن تمشي. جرّب ثلاث.
  • في «إذا… فإن…»: المثال المضاد الشرط فيه صح والنتيجة خطأ.
  • عكس «و» هو «أو».
  • لا تنسَ «lowest terms».
  • «يوجد» ما تنقض بمثال.
  • «حل وحيد» = وجود + وحدانية.
