الوجود والبرهان بالتناقض

الفصل كله خمس أنواع أسئلة. لكل نوع: بطاقة خطوات، وأمثلة محلولة سطر بسطر، وبعد كل مثال تمرين من نفس نوعه تحله بنفس الخطوات.

كيف تستخدمها

  1. امشِ بالترتيب. كل وحدة تبدأ بـ«بطاقة خطوات» فيها ثلاث خطوات تحفظها.
  2. كل مثال يمشي كذا: السؤال، ثم نفكر بالأرقام، ثم نكتب الجواب وتحت كل سطر معناه.
  3. بعد المثال يجي «دورك»: تمرين من نفس النوع. غطِّ المثال وحلّه، وبعدها شيّك من الحلول.
  4. مستعجل؟ امشِ على الصفحات اللي فوقها «أساسي» بس.

المثال المضاد: الفكرة بالأرقام

الجملة اللي تقول «لكل…» تطيح بقيمة وحدة تفشل عندها. هذي القيمة اسمها مثال مضاد.

نبدأ بأرقام (مثال السلايدات 1)

الجملة: «For every real number \(x\), \((x^2 - 1)^2 \gt 0\)». يعني: لكل عدد حقيقي x، \((x^2-1)^2\) أكبر من صفر. نجرب:

\(x\)0231
\((x^2-1)^2\)\((0-1)^2 = 1\)\((4-1)^2 = 9\)\((9-1)^2 = 64\)\((1-1)^2 = 0\)
أكبر من 0؟✓✓✓✗

ثلاث قيم مشت، بس عند \(x = 1\) طلع 0، و0 مو أكبر من 0. قيمة وحدة فشلت، فالجملة «لكل x» خاطئة.

نكتب (حل السلايدات)

1احسب
For \(x = 1\), \((x^2 - 1)^2 = (1^2 - 1)^2 = 0\).نكتب القيمة اللي فشلت، والحساب بالأرقام.
2احكم
Thus, \(x = 1\) is a counterexample.إذن \(x = 1\) مثال مضاد، والجملة خاطئة.

Definition. If the statement \(\forall x \in S, R(x)\) is false, then there exists some element \(x\) in the set \(S\) for which \(R(x)\) is false. Such an element \(x\) is called a counterexample of the false statement \(\forall x \in S, R(x)\).

بالعربي: لو الجملة «لكل x في S، \(R(x)\)» خاطئة، فلازم فيه عنصر x في S الجملة عنده خاطئة. هذا العنصر اسمه مثال مضاد.

Definition. If a statement \(P\) is shown to be false in some manner, then \(P\) is said to be disproved.

بالعربي: لما تثبت أن جملة خاطئة، نقول إنك نفيتها. فكلمة Disprove في السؤال معناها: اثبت أنها خاطئة.

بطاقة الخطوات: المثال المضاد

1جرّبقيم من المجموعة اللي في السؤال، لين تلقى وحدة تفشل. ابدأ بـ 0 و1 و\(-1\) و2.
2احسبواكتب القيمة والحساب بالأرقام: For \(x = \ldots\), …
3احكمThus, \(x = \ldots\) is a counterexample.

السؤال

Disprove the statement: If \(x \in \mathbb{Z}\), then \(\dfrac{x^2 + x}{x^2 - x} = \dfrac{x + 1}{x - 1}\).

بالعربي: انفِ الجملة: لكل عدد صحيح x، الكسرين متساويين.

نفكر

1قبل ما تجرّب أرقام عشوائية، اسأل: فيه قيمة تخلي مقام صفر؟ المقام \(x^2 - x\) يصير صفر عند \(x = 0\).
2عند \(x = 0\): الكسر الأيسر ما له قيمة أصلاً (قسمة على صفر)، والأيمن \(\frac{0 + 1}{0 - 1} = -1\). شي ما له قيمة ما يساوي \(-1\).

نكتب (حل السلايدات)

1القيمة
If \(x = 0\), then \(x^2 - x = 0\) and so \(\frac{x^2 + x}{x^2 - x}\) is not defined.عند \(x = 0\) المقام صفر، فالكسر الأيسر غير معرّف.
2احكم
On the other hand, if \(x = 0\), then \(\frac{x + 1}{x - 1} = -1\); so the expressions \(\frac{x^2 + x}{x^2 - x}\) and \(\frac{x + 1}{x - 1}\) are certainly not equal when \(x = 0\). Thus, \(x = 0\) is a counterexample to the statement.والكسر الأيمن يساوي \(-1\)، فالطرفين مو متساويين. إذن \(x = 0\) مثال مضاد.

مثال: أكثر من متغيرمثال السلايدات 4دورك

السؤال

Show that the statement “For positive integers \(a, b, c\), \(a^{b^c} = (a^b)^c\).” is false.

بالعربي: اثبت أن الجملة خاطئة: لكل أعداد صحيحة موجبة a و b و c، \(a^{b^c} = (a^b)^c\).

نفكر

1الفرق: في \(a^{b^c}\) تحسب \(b^c\) أول وترفع a له. وفي \((a^b)^c\) تحسب \(a^b\) أول وترفعه لـ c.
2نجرب \(a = b = c = 2\): \(2^{2^2} = 2^4 = 16\) و \((2^2)^2 = 4^2 = 16\). متساويين، ما نفعت!
3نغيّر c: \(a = 2,\ b = 2,\ c = 3\): \(2^{2^3} = 2^8 = 256\) و \((2^2)^3 = 4^3 = 64\). مختلفين ✗ هذا المثال المضاد.

نكتب (حل السلايدات)

1احسب
Let \(a = 2\), \(b = 2\) and \(c = 3\). Then \(a^{b^c} = 2^{2^3} = 2^8 = 256\), while \((a^b)^c = (2^2)^3 = 4^3 = 64\).نختار القيم، ونحسب كل طرف بالأرقام.
2احكم
Since \(256 \ne 64\), the positive integers \(a = 2\), \(b = 2\) and \(c = 3\) constitute a counterexample.الطرفين مختلفين، فهذي القيم مثال مضاد.

خمس تريكات للمثال المضاد

  1. ابدأ بالقيم السهلة: 0، 1، \(-1\)، 2، 3. أغلب الأمثلة المضادة في الكتاب منها.
  2. دوّر قيمة تخلي مقام صفر، يعني تخلي الجملة بدون معنى.
  3. في «إذا… فإن…»: الشرط صح والنتيجة خطأ. جهّز جدول فيه عمود لكل واحد.
  4. لو فيه أكثر من متغير، لا تخليهم متساويين.
  5. لا تكتب «الجملة خاطئة» وتسكت. اكتب القيمة، والحساب، وكلمة counterexample.
