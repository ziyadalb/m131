ثلاث طرق لنفس الجملةمثال توأم 5.36

جملة «إذا P فإن Q» تنبرهن بثلاث طرق. الفرق كله في أول سطر: وش تفترض، ووين تبي توصل.

الفرق في أول سطر

الطريقةتفترض (أول سطر)توصل لـ
مباشر (direct proof)P صحQ صح
عكس النقيض (proof by contrapositive)Q خطأP خطأ
تناقض (proof by contradiction)P صح و Q خطأشي مستحيل
السؤال

Prove that if \(n\) is an even integer, then \(3n + 7\) is odd.

بالعربي: اثبت: إذا n زوجي، فإن \(3n + 7\) فردي. هنا P هي «n زوجي»، و Q هي «\(3n + 7\) فردي».

نكتب: نفس الجملة بثلاث طرق

(a)مباشر
Assume that \(n\) is even. Then \(n = 2k\) for some integer \(k\). So \(3n + 7 = 6k + 7 = 2(3k + 3) + 1\). Since \(3k + 3\) is an integer, \(3n + 7\) is odd.افترضنا P (n زوجي)، ووصلنا لـ Q (\(3n + 7\) فردي).
(b)عكس النقيض
Assume that \(3n + 7\) is even. Then \(3n + 7 = 2k\) for some integer \(k\). So \(n = (3n + 7) - 2n - 7 = 2k - 2n - 7 = 2(k - n - 4) + 1\). Since \(k - n - 4\) is an integer, \(n\) is odd.افترضنا أن Q خطأ (\(3n + 7\) زوجي)، ووصلنا أن P خطأ (n فردي).
(c)تناقض
Assume, to the contrary, that there exists an even integer \(n\) such that \(3n + 7\) is even. Then \(n = 2x\) and \(3n + 7 = 2y\) for some integers \(x\) and \(y\). Hence \(3(2x) + 7 = 2y\), and so \(7 = 2y - 6x = 2(y - 3x)\). Since \(y - 3x\) is an integer, 7 is even, which is a contradiction.افترضنا P صح و Q خطأ مع بعض، فطلع أن 7 زوجي. مستحيل.
انتبه:لا تبدأ بـ «Assume that \(3n + 7\) is odd»: هذا افتراض للمطلوب نفسه.
أي طريقة؟لو السؤال حددها التزم فيها. لو ما حدد: جرّب المباشر أول.

5.36. Prove that if \(n\) is an odd integer, then \(7n - 5\) is even by (a) a direct proof, (b) a proof by contrapositive and (c) a proof by contradiction.

بالعربي: اثبت: إذا n فردي، فإن \(7n - 5\) زوجي، بثلاث طرق: (a) مباشر، (b) عكس النقيض، (c) تناقض.

قبل ما تكتب: حدّد P و Q. واكتب أول سطر لكل طريقة من ذاكرتك، وبعدها كمّل.

(a)مباشر
(b)عكس النقيض
(c)تناقض

تلميح (b): من \(7n - 5 = 2k + 1\) طلّع n لوحدها: \(n = (7n - 5) - 6n + 5\).

تلميح (c): \(n = 2x + 1\) و \(7n - 5 = 2y + 1\). عوّض الأولى في الثانية، وشوف أي عدد يطلع «زوجي» وهو مو زوجي.

5.39. Let \(x, y \in \mathbb{R}^+\). Prove that if \(x \le y\), then \(x^2 \le y^2\) by (a) a direct proof, (b) a proof by contrapositive and (c) a proof by contradiction.

بالعربي: x و y عددين حقيقيين موجبين. اثبت: إذا \(x \le y\) فإن \(x^2 \le y^2\)، بثلاث طرق.

قبل ما تكتب

1بأرقام: \(2 \le 3\) و \(4 \le 9\) ✓ وشرط «موجبين» مهم: \(-3 \le 2\) لكن \(9 \le 4\) خطأ.
2حركتين تحتاجهم: لو ضربت متباينة في عدد موجب، اتجاهها ما يتغير. و \(x^2 - y^2 = (x - y)(x + y)\).
(a)مباشر
(b)عكس النقيض
(c)تناقض

تلميح (a): اضرب \(x \le y\) في x مرة، وفي y مرة.

تلميح (b) و(c): عكس \(x^2 \le y^2\) هو \(x^2 \gt y^2\)، يعني \((x - y)(x + y) \gt 0\). و \(x + y\) موجب.

الحلولشيّك

تمرين 5.36

(a)مباشر
Assume that \(n\) is odd. Then \(n = 2k + 1\) for some integer \(k\). So \(7n - 5 = 7(2k + 1) - 5 = 14k + 2 = 2(7k + 1)\). Since \(7k + 1\) is an integer, \(7n - 5\) is even.افترضنا P ووصلنا لـ Q.
(b)عكس النقيض
Assume that \(7n - 5\) is odd. Then \(7n - 5 = 2k + 1\) for some integer \(k\). So \(n = (7n - 5) - 6n + 5 = 2k + 1 - 6n + 5 = 2(k - 3n + 3)\). Since \(k - 3n + 3\) is an integer, \(n\) is even.افترضنا أن Q خطأ، ووصلنا أن P خطأ (n زوجي).
(c)تناقض
Assume, to the contrary, that there exists an odd integer \(n\) such that \(7n - 5\) is odd. Then \(n = 2x + 1\) and \(7n - 5 = 2y + 1\) for some integers \(x\) and \(y\). Hence \(7(2x + 1) - 5 = 2y + 1\), so \(14x + 2 = 2y + 1\) and \(1 = 2y - 14x = 2(y - 7x)\). Since \(y - 7x\) is an integer, 1 is even, which is a contradiction.افترضنا P صح و Q خطأ، فطلع أن 1 زوجي. مستحيل.

تمرين 5.39

(a)مباشر
Assume that \(x \le y\). Since \(x \gt 0\), multiplying both sides by \(x\) gives \(x^2 \le xy\). Since \(y \gt 0\), multiplying both sides of \(x \le y\) by \(y\) gives \(xy \le y^2\). Therefore \(x^2 \le xy \le y^2\), and so \(x^2 \le y^2\).ضربنا المتباينة في x مرة وفي y مرة، وربطنا النتيجتين.
(b)عكس النقيض
Assume that \(x^2 \gt y^2\). Then \(x^2 - y^2 \gt 0\), and so \((x - y)(x + y) \gt 0\). Since \(x + y \gt 0\), dividing both sides by \(x + y\) gives \(x - y \gt 0\). Hence \(x \gt y\).افترضنا أن Q خطأ (\(x^2 \gt y^2\))، ووصلنا أن P خطأ (\(x \gt y\)).
(c)تناقض
Assume, to the contrary, that there exist positive real numbers \(x\) and \(y\) such that \(x \le y\) and \(x^2 \gt y^2\). Then \((x - y)(x + y) = x^2 - y^2 \gt 0\). Since \(x + y \gt 0\), it follows that \(x - y \gt 0\), and so \(x \gt y\). This contradicts \(x \le y\).افترضنا P صح و Q خطأ، فطلع \(x \gt y\) و \(x \le y\) مع بعض. مستحيل.
