ملخص الفصل 5: خمس أنواع أسئلة

الفصل كله خمس أنواع أسئلة. أول شي اعرف نوع السؤال من كلماته (الجدول تحت)، وبعدين امشِ على خطوات النوع. الأجوبة مكتوبة بالإنجليزي مثل ما تكتبها في الاختبار، وتحت كل جواب معناه بالعربي.

1المثال المضاد

متى يجيك: لما يقول لك اثبت إن الجملة غلط (Disprove)، والجملة تقول «لكل…».

الفكرة: جملة «لكل» تطيح برقم واحد بس يخالفها.

1جرّب أرقام من المجموعة اللي في السؤال، لين تلقى رقم يخرّبها.2اكتب الحساب بالأرقام.3قل إن هذا الرقم مثال مضاد.
مثالFor every even positive integer \(n\), \(12 \mid (n^2 - 4)\).يعني: لكل عدد زوجي موجب n، الـ 12 تقسم \(n^2 - 4\).

كيف تفكر: نجرب الأعداد الزوجية بالترتيب: \(n = 2\) يطلع 0، و12 تقسمه ✓. \(n = 4\) يطلع 12 ✓. \(n = 6\) يطلع 32، و12 ما تقسمه ✗. لقينا الرقم.

تكتبFalse. For \(n = 6\), \(n^2 - 4 = 32\) and \(12 \nmid 32\). Thus, \(n = 6\) is a counterexample.يعني: الجملة غلط. لما n = 6 يطلع 32، و12 ما تقسم 32. إذن 6 مثال مضاد.

⚠️ انتبه: أول رقم أو رقمين ممكن يمشون، فجرّب ثلاثة على الأقل. ولو الجملة «إذا… فإن…»، دوّر رقم يخلي الشرط صح والنتيجة غلط.

2البرهان بالتناقض

متى يجيك: لما يقول «There is no» (ما فيه…) أو «irrational» (غير نسبي).

الفكرة: تفترض عكس المطلوب، وتمشي بخطوات صحيحة لين توصل لشي مستحيل. معناها افتراضك غلط، والجملة صح.

1اكتب العكس: Assume, to the contrary, that …2امشِ بخطوات صحيحة: تعريف وحساب.3وصّل لشي مستحيل واكتب This is a contradiction.
مثال 1There is no smallest positive real number.يعني: ما فيه أصغر عدد حقيقي موجب.

كيف تفكر: أي عدد موجب تختاره، نصّه أصغر منه وبعده موجب. فما فيه «أصغر واحد».

تكتبAssume, to the contrary, that there is a smallest positive real number, say \(r\). Since \(0 \lt r/2 \lt r\), \(r/2\) is a positive real number smaller than \(r\). This is a contradiction.يعني: نفترض فيه أصغر عدد موجب، ونسميه r. بس نص r موجب وأصغر منه، وهذا يناقض إن r هو الأصغر.
مثال 2Prove that \(\sqrt{2}\) is irrational.يعني: اثبت إن \(\sqrt{2}\) ما ينكتب ككسر.

كيف تفكر: نفترض \(\sqrt{2} = a/b\)، كسر مبسّط لآخر حد. نربّع الطرفين، فيطلع إن a و b الاثنين زوجيين، يعني الكسر ينبسط بعد. تناقض!

تكتبAssume, to the contrary, that \(\sqrt{2}\) is rational. Then \(\sqrt{2} = a/b\), where \(a, b \in \mathbb{Z}\), \(b \ne 0\), and \(a/b\) is in lowest terms. So \(a^2 = 2b^2\), and \(a\) is even. Let \(a = 2c\). Then \(4c^2 = 2b^2\), so \(b^2 = 2c^2\) and \(b\) is even. Since \(a\) and \(b\) are both even, this contradicts that \(a/b\) is in lowest terms.يعني: \(a^2 = 2b^2\) فـ a زوجي. نكتبه 2c ونعوّض، فيطلع b زوجي بعد. والكسر المبسّط ما يكون بسطه ومقامه الاثنين زوجيين.

⚠️ انتبه: كيف تكتب العكس: «ما فيه» يصير «فيه». «غير نسبي» يصير «نسبي». «إذا P فإن Q» يصير «P صح و Q غلط». و«و» تصير «أو».

3ثلاث طرق

متى يجيك: لما يطلب نفس الجملة بثلاث طرق: direct و contrapositive و contradiction.

الفكرة: الجملة «إذا P فإن Q». الفرق بين الطرق بس في وش تفترض بأول سطر، ووين توصل.

1مباشر: تفترض P، وتوصل لـ Q.2عكس النقيض: تفترض إن Q غلط، وتوصل إن P غلط.3تناقض: تفترض P صح و Q غلط مع بعض، وتوصل لشي مستحيل.
مثالIf \(n\) is an even integer, then \(5n + 1\) is odd.يعني: لو n زوجي، فـ \(5n + 1\) فردي. هنا P = «n زوجي»، و Q = «\(5n + 1\) فردي».
(a) مباشرAssume that \(n\) is even. Then \(n = 2k\) for some integer \(k\). So \(5n + 1 = 10k + 1 = 2(5k) + 1\), which is odd.يعني: n زوجي فنكتبه 2k، ونعوّض. يطلع \(5n + 1\) على شكل \(2(\ldots) + 1\)، يعني فردي.
(b) عكس النقيضAssume that \(5n + 1\) is even. Then \(5n + 1 = 2k\) for some integer \(k\). So \(n = (5n + 1) - 4n - 1 = 2(k - 2n - 1) + 1\), which is odd.يعني: نفترض \(5n + 1\) زوجي (عكس Q)، ونطلّع n منها. يطلع n فردي (عكس P).
(c) تناقضAssume, to the contrary, that there is an even integer \(n\) such that \(5n + 1\) is even. Then \(n = 2x\) and \(5n + 1 = 2y\) for some integers \(x, y\). So \(10x + 1 = 2y\) and \(1 = 2(y - 5x)\). Thus 1 is even, which is a contradiction.يعني: نفترض n زوجي و \(5n + 1\) زوجي مع بعض. يطلع إن 1 زوجي، وهذا مستحيل.

⚠️ انتبه: لا تبدأ أبداً بإنك تفترض Q (إن \(5n + 1\) فردي)، لأن هذا هو اللي مطلوب منك تثبته.

4الوجود

متى يجيك: لما يقول «Prove: There exists …» (اثبت إنه يوجد…).

الفكرة: يكفي تجيب مثال واحد يحقق الشرط، وتتحقق منه بالأرقام.

1اختر الشي: رقم أو أرقام.2تحقق إنه يمشي مع كل شروط السؤال.3قل إنه هو المطلوب.
مثال 1There exists an integer whose cube equals its square.يعني: فيه عدد صحيح مكعبه يساوي مربعه.
تكتبSince \(1^3 = 1^2 = 1\), the integer 1 has the desired property.
مثال 2The equation \(x^5 + 2x - 5 = 0\) has a unique real solution between \(x = 1\) and \(x = 2\).يعني: المعادلة لها حل واحد بس بين 1 و2.

كيف تفكر: عند 1 الدالة سالبة (\(-2\))، وعند 2 موجبة (31)، فلازم تقطع الصفر بينهم. ولو فيه حلين، يطلع \(0 \lt 0\). مستحيل.

تكتبExistence. Let \(f(x) = x^5 + 2x - 5\). Since \(f\) is a polynomial, it is continuous on \([1, 2]\). Since \(f(1) = -2 \lt 0 \lt 31 = f(2)\), by the Intermediate Value Theorem there is \(c \in (1, 2)\) with \(f(c) = 0\).
Uniqueness. Assume, to the contrary, that there are two solutions \(a \lt b\) in \((1, 2)\). Then \(a^5 + 2a - 5 \lt b^5 + 2b - 5\), so \(0 \lt 0\), a contradiction.يعني: «حل وحيد» (unique) جزأين: إنه موجود (بالقيمة الوسطى)، وإنه واحد بس (بالتناقض).

5نفي الوجود

متى يجيك: لما يقول «Disprove: There exists …» (اثبت إنه ما يوجد…).

الفكرة: هنا مثال واحد ما يكفي. لازم تثبت إن الشي غلط مع كل الأرقام.

1اقلب السؤال: بدل «فيه رقم كذا»، تثبت إن كل الأرقام عكس كذا.2خذ رقم عام (مو رقم معيّن) واكتبه بالرموز.3اثبت بالحساب، أو بحالتين: زوجي وفردي.
مثالDisprove: There exists an integer \(n\) such that \(n^3 - n + 1\) is even.يعني: اثبت إنه ما فيه عدد صحيح يخلي \(n^3 - n + 1\) زوجي.

كيف تفكر: نجرب 0، 1، 2، 3: يطلع 1، 1، 7، 25، كلها فردية. فنثبت إنها فردية دايماً: مرة n زوجي، ومرة n فردي.

تكتبWe show that \(n^3 - n + 1\) is odd for every \(n \in \mathbb{Z}\).
Case 1. \(n = 2a\): \(n^3 - n + 1 = 8a^3 - 2a + 1 = 2(4a^3 - a) + 1\), which is odd.
Case 2. \(n = 2b + 1\): \(n^3 - n + 1 = 8b^3 + 12b^2 + 4b + 1 = 2(4b^3 + 6b^2 + 2b) + 1\), which is odd.يعني: في الحالتين يطلع الناتج على شكل \(2(\ldots) + 1\)، يعني فردي دايماً.

⚠️ انتبه: لا تخلط: «Disprove: For every» يكفيها مثال واحد. أما «Disprove: There exists» فلازم برهان لكل الأرقام.
