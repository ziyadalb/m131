القسمة: حركة «اعزل وعوّض»

من الفرض اعزل القوة لوحدها، وعوّضها في \(P(k+1)\). الباقي يطلع مضاعف للعدد تلقائياً.

أول شي: \(a \mid b\) معناها \(b = ax\) لعدد صحيح x. أول ما تشوف علامة القسمة حوّلها لمعادلة، لأن المعادلة تقدر تعوّض فيها.

1حوّل الفرض لمعادلة: \(2^{2k} - 1 = 3x\).
2اعزل القوة: \(2^{2k} = 3x + 1\).
3في \(P(k+1)\) طلّع القوة القديمة: \(2^{2k+2} = 4 \cdot 2^{2k}\)، وعوّض.
4طلّع العدد عامل مشترك، واكتب Since … is an integer.

Result 6.11. For every nonnegative integer \(n\), \(\;3 \mid (2^{2n} - 1)\).

بالعربي:لكل عدد صحيح غير سالب n (يعني 0, 1, 2, …)، العدد \(2^{2n} - 1\) يقبل القسمة على 3.

Base
When \(n = 0\), \(2^{2n} - 1 = 0\), and \(3 \mid 0\).
Assume
Assume that \(3 \mid (2^{2k} - 1)\) for a nonnegative integer \(k\). Then \(2^{2k} - 1 = 3x\) for some integer \(x\), so \(2^{2k} = 3x + 1\).
Show
We show that \(3 \mid (2^{2k+2} - 1)\).
Step
\(2^{2k+2} - 1 = 4 \cdot 2^{2k} - 1 = 4(3x + 1) - 1 = 12x + 3 = 3(4x + 1).\) Since \(4x + 1\) is an integer, \(3 \mid (2^{2k+2} - 1)\).
Conclude
By the Principle of Mathematical Induction, \(3 \mid (2^{2n} - 1)\) for every nonnegative integer \(n\).
تحذير الكتاب نفسه:\(4 \cdot 2^{2k} - 1\) مو نفس \(4(2^{2k} - 1)\). عشان كذا نعوّض \(2^{2k} = 3x + 1\)، مو \(2^{2k} - 1 = 3x\).
انتبه للبداية:السؤال قال nonnegative، فالأساس \(n = 0\) مو 1. اقرأ المجموعة دائماً: positive تبدأ من 1، و nonnegative تبدأ من 0. والبداية من عدد غير 1 قاعدتها في الوحدة 5 .

Result 6.12. For every nonnegative integer \(n\), \(\;9 \mid (4^{3n} - 1)\).

بالعربي:لكل عدد صحيح غير سالب n، العدد \(4^{3n} - 1\) يقبل القسمة على 9.

Base
When \(n = 0\), \(4^{3n} - 1 = 0\). Since \(9 \mid 0\), the statement is true when \(n = 0\).
Assume
Assume that \(9 \mid (4^{3k} - 1)\), where \(k\) is a nonnegative integer. Then \(4^{3k} - 1 = 9x\) for some integer \(x\). Hence, \(4^{3k} = 9x + 1\).
Show
We show that \(9 \mid (4^{3k+3} - 1)\).
Step
\[4^{3k+3} - 1 = 4^3 \cdot 4^{3k} - 1 = 64(9x + 1) - 1 = 64 \cdot 9x + 63 = 9(64x + 7).\] Since \(64x + 7\) is an integer, \(9 \mid (4^{3k+3} - 1)\).
Conclude
By the Principle of Mathematical Induction, \(9 \mid (4^{3n} - 1)\) for every nonnegative integer \(n\).
ملاحظة من الكتاب:ما ضربنا \(64 \cdot 9\)، لأننا بنطلّع 9 عامل مشترك في الخطوة اللي بعدها. خل العدد اللي تقسم عليه ظاهر.

  3. بعد التعويض تطلّع العدد عامل مشترك: \(9(64x + 7)\).

Theorem 6.16 بالعربي: كم مجموعة جزئية؟

قبل البرهان افهم وش تقول النظرية: كل ما زاد عنصر واحد، يتضاعف عدد المجموعات الجزئية.

Theorem 6.16. If \(A\) is a finite set of cardinality \(n \ge 0\), then the cardinality of its power set \(\mathcal{P}(A)\) is \(2^n\).

بالعربي:إذا كانت A مجموعة منتهية عدد عناصرها n (حيث \(n \ge 0\))، فإن عدد عناصر مجموعة القوة \(\mathcal{P}(A)\) يساوي \(2^n\).

الكلمات

  • cardinality: عدد العناصر، ونكتبه \(|A|\).
  • power set \(\mathcal{P}(A)\): مجموعة كل المجموعات الجزئية من A، ومنها \(\emptyset\) و A نفسها.
A\(\mathcal{P}(A)\)العدد
\(\emptyset\)\(\{\emptyset\}\)\(1 = 2^0\)
\(\{1\}\)\(\{\emptyset,\ \{1\}\}\)\(2 = 2^1\)
\(\{1, 2\}\)\(\{\emptyset,\ \{1\},\ \{2\},\ \{1, 2\}\}\)\(4 = 2^2\)

ليش \(2^n\)؟ الفكرة بدون رموز

عشان تبني مجموعة جزئية، تمر على كل عنصر وتقرر: داخل أو برا. خيارين لكل عنصر، وعندك n عنصر، فعدد الطرق \(2 \times 2 \times \cdots \times 2 = 2^n\).

في الاختبار:الفكرة هذي للفهم بس. البرهان المطلوب بالاستقراء، وتلقاه محلول في الصفحة الجاية.

مثال محلول: الاستقراء على عدد العناصرمن السلايدات

هنا n هو عدد عناصر المجموعة، و \(P(n)\) جملة «إذا… فإن…». الفرض عن أي مجموعة فيها k عنصر، والخطوة عن مجموعة فيها \(k + 1\).

Theorem 6.16. If \(A\) is a finite set of cardinality \(n \ge 0\), then the cardinality of its power set \(\mathcal{P}(A)\) is \(2^n\).

Base
If \(A\) is a set with \(|A| = 0\), then \(A = \emptyset\). Thus, \(\mathcal{P}(A) = \{\emptyset\}\) and so \(|\mathcal{P}(A)| = 1 = 2^0\). Therefore, the theorem is true for \(n = 0\).
Assume
Assume that if \(B\) is any set with \(|B| = k\) for some nonnegative integer \(k\), then \(|\mathcal{P}(B)| = 2^k\).
Show
We show that if \(C\) is a set with \(|C| = k + 1\), then \(|\mathcal{P}(C)| = 2^{k+1}\). Let \(C = \{c_1, c_2, \ldots, c_{k+1}\}\).
Step
By the inductive hypothesis, there are \(2^k\) subsets of the set \(\{c_1, c_2, \ldots, c_k\}\), that is, there are \(2^k\) subsets of \(C\) not containing \(c_{k+1}\). Any subset of \(C\) containing \(c_{k+1}\) can be expressed as \(D \cup \{c_{k+1}\}\), where \(D \subseteq \{c_1, c_2, \ldots, c_k\}\). Again, by the inductive hypothesis, there are \(2^k\) such subsets \(D\). Therefore, there are \(2^k + 2^k = 2 \cdot 2^k = 2^{k+1}\) subsets of \(C\).
Conclude
By the Principle of Mathematical Induction, it follows for every nonnegative integer \(n\) that if \(|A| = n\), then \(|\mathcal{P}(A)| = 2^n\).

Base

Assume
Assume that \(3^k \gt k^2\) for a positive integer \(k\).
Show

Small k
If \(k = 1\), then \(3^{k+1} = 9 \gt 4 = (k+1)^2\). So we may assume that \(k \ge 2\).
Step

Conclude
By the Principle of Mathematical Induction, \(3^n \gt n^2\) for every positive integer \(n\).

تمرين 6.27

Base
Since \(1 \le 2 - \frac{1}{1} = 1\), the statement is true for \(n = 1\).
Assume
Assume that \(1 + \frac{1}{4} + \cdots + \frac{1}{k^2} \le 2 - \frac{1}{k}\) for a positive integer \(k\).
Show
We show that \(1 + \frac{1}{4} + \cdots + \frac{1}{(k+1)^2} \le 2 - \frac{1}{k+1}\).
Step
Since \(k(k+1) \lt (k+1)^2\), we have \(\frac{1}{(k+1)^2} \lt \frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}\). Conclude

تمرين 6.19

Base
For \(n = 2\): if \(x_1 x_2 = 0\), then \(x_1 = 0\) or \(x_2 = 0\) by the given fact.
Assume
Assume for some integer \(k \ge 2\) that whenever \(y_1, \ldots, y_k\) are real numbers with \(y_1 y_2 \cdots y_k = 0\), at least one \(y_i\) is \(0\).
Show
Let \(x_1, \ldots, x_{k+1}\) be real numbers with \(x_1 x_2 \cdots x_{k+1} = 0\). We show that some \(x_i = 0\).
Step
Since \((x_1 x_2 \cdots x_k) \cdot x_{k+1} = 0\), the given fact gives \(x_1 \cdots x_k = 0\) or \(x_{k+1} = 0\). If \(x_{k+1} = 0\), we are done. Otherwise \(x_1 \cdots x_k = 0\), and by the inductive hypothesis \(x_i = 0\) for some \(i\) with \(1 \le i \le k\).
Conclude
By the Principle of Mathematical Induction, the implication holds for every integer \(n \ge 2\).
