السؤال

Prove that \(\frac{1}{2\cdot 3} + \frac{1}{3\cdot 4} + \cdots + \frac{1}{(n+1)(n+2)} = \frac{n}{2n+4}\) for every positive integer \(n\).

بالعربي: اثبت أن مجموع هذي الكسور يساوي \(n/(2n+4)\)، لكل عدد صحيح موجب n.

نفكر

1نفس خطوات مثال 1. الجديد بس الكسور: الحد الجديد عند \(k+1\) هو \(\frac{1}{(k+2)(k+3)}\) (بدّلنا n بـ \(k+1\)).
2نبدّل كل اللي قبله بالفرض \(\frac{k}{2k+4}\)، ونكتب \(2k + 4 = 2(k+2)\) عشان يبان المقام المشترك \(2(k+2)(k+3)\).
3الهدف \(\frac{k+1}{2k+6}\) ما فيه \((k+2)\)، فلازم البسط فيه \((k+2)\) وبيختصر: \(k^2 + 3k + 2 = (k+1)(k+2)\).

نكتب

Baseالأساس
Since \(\frac{1}{2\cdot 3} = \frac{1}{6} = \frac{1}{2\cdot 1 + 4}\), the formula holds for \(n = 1\).عند \(n = 1\) الطرفين يساوون \(1/6\).
Assumeالفرض
Assume that \(\frac{1}{2\cdot 3} + \cdots + \frac{1}{(k+1)(k+2)} = \frac{k}{2k+4}\) for a positive integer \(k\).نفترض أنها صحيحة عند k.
Showالمطلوب
We show that \(\frac{1}{2\cdot 3} + \cdots + \frac{1}{(k+2)(k+3)} = \frac{k+1}{2k+6}\).نثبتها عند \(k + 1\).
Stepالخطوة
\[\begin{aligned} \frac{1}{2\cdot 3} + \cdots + \frac{1}{(k+2)(k+3)} &= \frac{k}{2(k+2)} + \frac{1}{(k+2)(k+3)} = \frac{k(k+3) + 2}{2(k+2)(k+3)} \\ &= \frac{(k+1)(k+2)}{2(k+2)(k+3)} = \frac{k+1}{2k+6}. \end{aligned}\]بدّلنا الكسور اللي قبل الحد الجديد بالفرض، ووحّدنا المقام، وحلّلنا البسط، واختصرنا \((k+2)\).

Proofالبرهان
Let \(S = 1 + 3 + \cdots + (2n-1)\). Writing the terms in reverse order, \(S = (2n-1) + (2n-3) + \cdots + 1\). Adding the two expressions term by term, each of the \(n\) pairs has sum \(2n\), so \(2S = n(2n) = 2n^2\). Hence \(S = n^2\).كتبنا المجموع مرتين، مرة بالعكس، وجمعنا عمود عمود: كل عمود \(2n\)، وعندنا n عمود. فـ \(2S = 2n^2\)، يعني \(S = n^2\).
