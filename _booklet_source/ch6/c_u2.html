4- For each positive integer \(n\), \(1 + 2 + 3 + \cdots + n = \frac{n(n+1)}{2}\). (3 marks)

بالعربي: مجموع الأعداد من 1 إلى n يساوي n(n + 1)/2.

بالأرقام: n = 3: 1 + 2 + 3 = 6، و \(\frac{3 \cdot 4}{2} = 6\) ✓. حركة الخطوة في المجاميع: مجموع k + 1 = (مجموع k) + آخر حد. مجموع k تبدّله بالفرض، وبعدها تبسّط لين يطلع المطلوب.

نكتب (برهان السلايدات)

1الأساس↩ ورقة الميدات
We employ induction. Let \(P(n): 1 + 2 + 3 + \cdots + n = \frac{n(n+1)}{2}\). Since \(1 = \frac{1 \cdot 2}{2}\), the statement \(P(1)\) is true.سمّينا الجملة P(n) زي السلايدات، وعوّضنا n = 1: الطرفين 1.
2الفرض
Assume that \(P(k)\) is true for an arbitrary positive integer \(k\), that is, assume that \(1 + 2 + 3 + \cdots + k = \frac{k(k+1)}{2}\).نفس الجملة، بس k بدل n.
3المطلوب
We show that \(P(k+1)\) is true, that is, we show that \(1 + 2 + 3 + \cdots + (k+1) = \frac{(k+1)(k+2)}{2}\).نفس الجملة بـ k + 1. هذا الهدف.
4الخطوة
Thus, \[\begin{aligned} 1 + 2 + 3 + \cdots + (k+1) &= \hyp{(1 + 2 + 3 + \cdots + k)} + (k+1) = \hyp{\frac{k(k+1)}{2}} + (k+1) \\ &= \frac{k(k+1) + 2(k+1)}{2} = \frac{(k+1)(k+2)}{2}, \end{aligned}\] as desired.فصلنا آخر حد (k + 1). الباقي بالأزرق هو مجموع k، فبدّلناه بالفرض. بعدها مقام مشترك، و (k + 1) عامل مشترك.
5الختام
By the Principle of Mathematical Induction, \(P(n)\) is true for every positive integer \(n\).اسم المبدأ كامل.
انتبه:لا تكتب المطلوب كأنه صحيح وتشتغل على طرفيه. ابدأ من طرف واحد (المجموع)، وامشِ لين توصل للطرف الثاني.

4. For every positive integer \(n\), \(1 + 3 + 5 + \cdots + (2n - 1) = n^2\).

بالعربي: مجموع أول n أعداد فردية يساوي n². وهو تمرين 6.4 في الخطة، وجا بعد في نهائي 1446.

بالأرقام: 1 + 3 + 5 = 9 = 3² ✓. نفس حركة مثال 1. الفرق الوحيد: آخر حد عند k + 1 هو \(2(k+1) - 1 = 2k + 1\).

نكتب

1الأساس↩ ورقة الميدات
Since \(1 = 1^2\), the statement is true for \(n = 1\).عوّضنا n = 1.
2الفرض
Assume that \(1 + 3 + 5 + \cdots + (2k-1) = k^2\) for an arbitrary positive integer \(k\).نفس الجملة بـ k.
3المطلوب
We show that \(1 + 3 + 5 + \cdots + (2k+1) = (k+1)^2\).آخر حد صار 2k + 1، والأيمن (k + 1)².
4الخطوة
Thus, \(1 + 3 + \cdots + (2k+1) = \hyp{[1 + 3 + \cdots + (2k-1)]} + (2k+1) = \hyp{k^2} + 2k + 1 = (k+1)^2\), as desired.فصلنا آخر حد، وبدّلنا الأزرق بـ k² من الفرض. و k² + 2k + 1 مربع كامل.
5الختام
By the Principle of Mathematical Induction, \(1 + 3 + 5 + \cdots + (2n-1) = n^2\) for every positive integer \(n\).اسم المبدأ كامل.
انتبه:آخر حد في المطلوب: عوّض n = k + 1 في (2n − 1)، يطلع 2k + 1. لا تكتبه (2k − 1) + 1.

Result. For every positive integer \(n\), \(\frac{1}{2\cdot 3} + \frac{1}{3\cdot 4} + \cdots + \frac{1}{(n+1)(n+2)} = \frac{n}{2n+4}\).

بالعربي: مجموع كسور. نفس القالب، بس الخطوة فيها مقام مشترك.

بالأرقام: n = 2: \(\frac{1}{6} + \frac{1}{12} = \frac{1}{4}\)، و \(\frac{2}{8} = \frac{1}{4}\) ✓. تريك: لا تفك المقامات. المطلوب \(\frac{k+1}{2(k+3)}\) يقول لك إن \((k + 2)\) لازم ينحذف، فخلّه عامل مشترك.

نكتب (برهان السلايدات)

1الأساس
We use induction. Since \(\frac{1}{2\cdot 3} = \frac{1}{2\cdot 1 + 4} = \frac{1}{6}\), the formula holds for \(n = 1\).
2الفرض
Assume that \(\frac{1}{2\cdot 3} + \frac{1}{3\cdot 4} + \cdots + \frac{1}{(k+1)(k+2)} = \frac{k}{2k+4}\) for a positive integer \(k\).
3المطلوب
We show that \(\frac{1}{2\cdot 3} + \frac{1}{3\cdot 4} + \cdots + \frac{1}{(k+2)(k+3)} = \frac{k+1}{2(k+1)+4} = \frac{k+1}{2k+6}\).آخر حد صار \(\frac{1}{(k+2)(k+3)}\).
4الخطوة
Observe that \[\begin{aligned} \frac{1}{2\cdot 3} + \cdots + \frac{1}{(k+2)(k+3)} &= \hyp{\left[\frac{1}{2\cdot 3} + \cdots + \frac{1}{(k+1)(k+2)}\right]} + \frac{1}{(k+2)(k+3)} \\ &= \hyp{\frac{k}{2k+4}} + \frac{1}{(k+2)(k+3)} \\ &= \frac{k}{2(k+2)} + \frac{1}{(k+2)(k+3)} \\ &= \frac{k(k+3) + 2}{2(k+2)(k+3)} = \frac{k^2 + 3k + 2}{2(k+2)(k+3)} \\ &= \frac{(k+1)(k+2)}{2(k+2)(k+3)} = \frac{k+1}{2(k+3)} = \frac{k+1}{2k+6}, \end{aligned}\] giving us the desired result.بدّلنا الأزرق بالفرض، ووحّدنا المقام \(2(k+2)(k+3)\)، وحلّلنا \(k^2 + 3k + 2\)، فانحذف \((k + 2)\).
5الختام
By the Principle of Mathematical Induction, \(\frac{1}{2\cdot 3} + \cdots + \frac{1}{(n+1)(n+2)} = \frac{n}{2n+4}\) for every positive integer \(n\).
