The more general principle. For a fixed integer \(m\), let \(S = \{i \in \mathbb{Z} : i \ge m\}\). For each integer \(n \in S\), let \(P(n)\) be a statement. If (1) \(P(m)\) is true and (2) the implication “If \(P(k)\), then \(P(k+1)\).” is true for every integer \(k \in S\), then \(P(n)\) is true for every integer \(n \in S\).

بالعربي: نفس المبدأ، بس البداية m بدل 1: الأساس عند m، والفرض لـ k ≥ m.

مثال 3 في السلايدات

Result. For every nonnegative integer \(n\), \(2^n \gt n\).

بالعربي: البداية من 0.

حركة الخطوة في المتباينات: ابدأ من الطرف حق k + 1 (\(2^{k+1} = 2 \cdot 2^k\))، واستخدم الفرض، وبعدها خطوة صغيرة توصلك. هنا الخطوة الصغيرة \(k + k \ge k + 1\) تحتاج \(k \ge 1\)، فـ k = 0 نسويها لحالها (سطر ★).

نكتب (برهان السلايدات)

1الأساس
We proceed by induction. The inequality holds for \(n = 0\) since \(2^0 \gt 0\).\(2^0 = 1\)، و 1 > 0.
2الفرض
Assume that \(2^k \gt k\), where \(k\) is a nonnegative integer.
3المطلوب
We show that \(2^{k+1} \gt k + 1\).
★k = 0
When \(k = 0\), we have \(2^{k+1} = 2 \gt 1 = k + 1\). We therefore assume that \(k \ge 1\).سطر ★: نخلص من k = 0 لحالها.
4الخطوة
Then \(2^{k+1} = 2 \cdot \hyp{2^k} \gt 2\hyp{k} = k + k \ge k + 1\).بدّلنا \(2^k\) بالفرض (أكبر من k)، و \(k \ge 1\) تعطي \(k + k \ge k + 1\).
5الختام
By the Principle of Mathematical Induction, \(2^n \gt n\) for every nonnegative integer \(n\).اسم المبدأ كامل، ومعه البداية الصح.
انتبه:اقرأ البداية من السؤال: positive من 1، و nonnegative من 0، و n ≥ 5 من 5.

Result. For every integer \(n \ge 5\), \(2^n \gt n^2\).

بالعربي: البداية 5، لأن \(2^4 = 16\) مو أكبر من \(4^2 = 16\).

بالأرقام: n = 4: 16 > 16 ✗، و n = 5: 32 > 25 ✓. الخطوة: \(2^{k+1} = 2 \cdot 2^k \gt 2k^2\)، وبعدها نستخدم \(k \ge 5\) مرتين: \(k^2 \ge 5k\) و \(3k \ge 15\).

نكتب (برهان السلايدات)

1الأساس
We proceed by induction. Since \(2^5 \gt 5^2\), the inequality holds for \(n = 5\).32 > 25.
2الفرض
Assume that \(2^k \gt k^2\) where \(k \ge 5\).ولا تنسَ «where k ≥ 5».
3المطلوب
We show that \(2^{k+1} \gt (k+1)^2\).
4الخطوة
Observe that \[\begin{aligned} 2^{k+1} = 2 \cdot \hyp{2^k} \gt 2\hyp{k^2} = k^2 + k^2 &\ge k^2 + 5k = k^2 + 2k + 3k \\ &\ge k^2 + 2k + 15 \gt k^2 + 2k + 1 = (k+1)^2. \end{aligned}\] Therefore, \(2^{k+1} \gt (k+1)^2\).الفرض (الأزرق)، وبعدها \(k \ge 5\): \(k^2 \ge 5k\) و \(3k \ge 15\). والهدف \(k^2 + 2k + 1\).
5الختام
By the Principle of Mathematical Induction, \(2^n \gt n^2\) for every integer \(n \ge 5\).اسم المبدأ كامل، ومعه البداية الصح.

Theorem. If \(A\) is a finite set of cardinality \(n \ge 0\), then the cardinality of its power set \(\mathcal{P}(A)\) is \(2^n\).

بالعربي: لو A فيها n عنصر، فعدد المجموعات الجزئية منها \(2^n\). البداية من 0 (المجموعة الفاضية).

الخطوة: المجموعات الجزئية من C (فيها k + 1 عنصر) نوعين: اللي ما فيها العنصر الأخير (\(2^k\) بالفرض)، واللي فيها (\(2^k\) بعد). المجموع \(2^{k+1}\).

نكتب (برهان السلايدات)

1الأساس
We proceed by induction. If \(A\) is a set with \(|A| = 0\), then \(A = \emptyset\). Thus, \(\mathcal{P}(A) = \{\emptyset\}\) and so \(|\mathcal{P}(A)| = 1 = 2^0\). Therefore, the theorem is true for \(n = 0\).
2الفرض
Assume that if \(B\) is any set with \(|B| = k\) for some nonnegative integer \(k\), then \(|\mathcal{P}(B)| = 2^k\).
3المطلوب
We show that if \(C\) is a set with \(|C| = k + 1\), then \(|\mathcal{P}(C)| = 2^{k+1}\). Let \(C = \{c_1, c_2, \ldots, c_{k+1}\}\).
4الخطوة
By the inductive hypothesis, there are \(\hyp{2^k}\) subsets of the set \(\{c_1, c_2, \ldots, c_k\}\), that is, there are \(2^k\) subsets of \(C\) not containing \(c_{k+1}\). Any subset of \(C\) containing \(c_{k+1}\) can be expressed as \(D \cup \{c_{k+1}\}\), where \(D \subseteq \{c_1, c_2, \ldots, c_k\}\). Again, by the inductive hypothesis, there are \(\hyp{2^k}\) such subsets \(D\). Therefore, there are \(2^k + 2^k = 2 \cdot 2^k = 2^{k+1}\) subsets of \(C\).
5الختام
By the Principle of Mathematical Induction, it follows for every nonnegative integer \(n\) that if \(|A| = n\), then \(|\mathcal{P}(A)| = 2^n\).

مثال الكتاب 6.14: \(x^n\) زوجيمثال الكتاب 6.14

مثال من الكتاب في 6.2 (ما انسأل للحين)

Result 6.14. Let \(x \in \mathbb{Z}\). For every integer \(n \ge 2\), \(x^n\) is even if and only if \(x\) is even.

بالعربي: إذا وفقط إذا: اتجاه بالمباشر، والاتجاه الثاني بالاستقراء من n = 2. وتنفعك في «\(\sqrt[3]{2}\) غير نسبي» في الفصل 5.

الاتجاه الصعب: لو \(x^{k+1} = x \cdot x^k\) زوجي، فواحد من الاثنين زوجي (نظرية 3.17). لو x زوجي خلصنا، ولو \(x^k\) زوجي فالفرض يقول x زوجي.

نكتب (حل الكتاب)

⇐مباشر
Assume, first, that \(x\) is even. Then \(x = 2y\) for some integer \(y\). Hence, \(x^n = x \cdot x^{n-1} = (2y)x^{n-1} = 2\left(yx^{n-1}\right)\). Since \(yx^{n-1}\) is an integer, \(x^n\) is even.x زوجي، فـ \(x^n\) زوجي.
1الأساس
We now verify the converse, namely if \(x^n\) is even, where \(n \ge 2\), then \(x\) is even. We proceed by induction. If \(x^2\) is even, then we have already seen that \(x\) is even. Hence, the statement is true for \(n = 2\).البداية من 2، والحالة n = 2 نعرفها من الفصل 3.
2الفرض
Assume that if \(x^k\) is even for some integer \(k \ge 2\), then \(x\) is even.
3المطلوب
We show that if \(x^{k+1}\) is even, then \(x\) is even.
4الخطوة
Let \(x^{k+1}\) be an even integer. Then \(x \cdot x^k\) is even. By Theorem 3.17, \(x\) or \(x^k\) is even. If \(x\) is even, then the result is proved. On the other hand, if \(\hyp{x^k}\) is even, then, by the induction hypothesis, \(x\) is even as well.
5الختام
By the Principle of Mathematical Induction, it follows, for every integer \(n \ge 2\), that if \(x^n\) is even, then \(x\) is even.
