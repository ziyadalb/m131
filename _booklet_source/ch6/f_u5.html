The Strong Principle of Mathematical Induction. For each positive integer \(n\), let \(P(n)\) be a statement. If (a) \(P(1)\) is true and (b) the implication “If \(P(i)\) for every integer \(i\) with \(1 \le i \le k\), then \(P(k+1)\).” is true for every positive integer \(k\), then \(P(n)\) is true for every positive integer \(n\).

بالعربي: الفرق عن العادي: الفرض يغطي كل الأعداد من 1 إلى k، مو k بس.

Recursively-defined sequence. Only the first term or the first few terms are defined specifically (the initial values); then \(a_n\) is expressed in terms of earlier terms (the recurrence relation).

بالعربي: المتتابعة التكرارية: أول حد أو أول حدّين معطيين، وكل حد بعدها يطلع من اللي قبله بقانون.

ليش قوي؟ في \(a_n = 2a_{n-1} - a_{n-2}\) كل حد يحتاج حدّين قبله. فالفرض لازم يعطيك \(a_k\) و \(a_{k-1}\) مع بعض، والفرض العادي يعطيك \(a_k\) بس.

بالأرقام (من السلايدات): \(a_1 = 1\)، \(a_2 = 3\)، و \(a_n = 2a_{n-1} - a_{n-2}\)

Result 6.23. If \(r\) is a nonzero real number such that \(r + \frac{1}{r}\) is an integer, then \(r^n + \frac{1}{r^n}\) is an integer for every positive integer \(n\).

بالعربي: لو \(r + \frac{1}{r}\) عدد صحيح، فكل \(r^n + \frac{1}{r^n}\) عدد صحيح. مثلاً \(r = \frac{3 + \sqrt{5}}{2}\) يعطي \(r + \frac{1}{r} = 3\).

التريك: \(\left(r^k + \frac{1}{r^k}\right)\left(r + \frac{1}{r}\right) = \left(r^{k+1} + \frac{1}{r^{k+1}}\right) + \left(r^{k-1} + \frac{1}{r^{k-1}}\right)\). يعني الحد الجديد يطلع من الحد k والحد k − 1 مع بعض، فنحتاج الاستقراء القوي.

نكتب (حل الكتاب، ومعه سطر ★)

1الأساس
We use the Strong Principle of Mathematical Induction. Since \(r + \frac{1}{r} = r^1 + \frac{1}{r^1}\) is an integer, the statement is true for \(n = 1\).
2الفرض
Assume for an arbitrary integer \(k \ge 1\) that \(m_i = r^i + \frac{1}{r^i}\) is an integer for every integer \(i\) with \(1 \le i \le k\).
3المطلوب
We show that \(r^{k+1} + \frac{1}{r^{k+1}}\) is an integer.
★k = 1
If \(k = 1\), then \(r^{k+1} + \frac{1}{r^{k+1}} = r^2 + \frac{1}{r^2} = \left(r + \frac{1}{r}\right)^2 - 2\) is an integer. So we may assume that \(k \ge 2\).الخطوة تحتاج \(m_{k-1}\)، ولما k = 1 يصير \(m_0\) وهو برا الفرض.
4الخطوة
Observe that \[r^{k+1} + \frac{1}{r^{k+1}} = \hyp{\left(r^k + \frac{1}{r^k}\right)}\left(r + \frac{1}{r}\right) - \hyp{\left(r^{k-1} + \frac{1}{r^{k-1}}\right)} = m_k m_1 - m_{k-1},\] which is an integer by the inductive hypothesis.
5الختام
By the Strong Principle of Mathematical Induction, \(r^n + \frac{1}{r^n}\) is an integer for every positive integer \(n\).

بالعربي: من القسم 6.4: برا خطة المقرر، بس موجود في السلايدات. اقرأه بعد ما تخلص الباقي.

نفرض العكس، وأصغر عدد تكون الجملة غلط عنده نسميه m (الترتيب الحسن يضمن وجوده)، واسمه minimum counterexample. كل عدد أصغر من m الجملة صحيحة عنده، وهذا يلعب دور الفرض. نثبتها عند m بعد، فيطلع تناقض.

نكتب (حل السلايدات)

1نعكس
Assume, to the contrary, that there are positive integers \(n\) such that \(6 \nmid (n^3 - n)\). Then there is a smallest positive integer \(n\) such that \(6 \nmid (n^3 - n)\). Let \(m\) be this integer.
2الصغار
If \(n = 1\), then \(n^3 - n = 0\); while if \(n = 2\), then \(n^3 - n = 6\). Since \(6 \mid 0\) and \(6 \mid 6\), it follows that \(6 \mid (n^3 - n)\) for \(n = 1\) and \(n = 2\). Therefore \(m \ge 3\). So, we can write \(m = k + 2\), where \(1 \le k \lt m\).
3الحساب
Observe that \[\begin{aligned} m^3 - m &= (k+2)^3 - (k+2) = (k^3 + 6k^2 + 12k + 8) - (k + 2) \\ &= (k^3 - k) + (6k^2 + 12k + 6). \end{aligned}\] Since \(k \lt m\), it follows that \(6 \mid (k^3 - k)\). Hence, \(\hyp{k^3 - k = 6x}\) for some integer \(x\). So, we have \(m^3 - m = 6x + 6(k^2 + 2k + 1) = 6(x + k^2 + 2k + 1)\).ليش k + 2؟ عشان يطلع \(k^3 - k\) (صحيح لأن k أصغر من m)، والباقي مضاعف 6 على طول.
4التناقض
Since \(x + k^2 + 2k + 1\) is an integer, \(6 \mid (m^3 - m)\), which produces a contradiction.
انتبه:لو السؤال قال «by minimum counterexample» لازم هالطريقة، مو الاستقراء.
